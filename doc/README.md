## 阅读路线

- 第一次接入：1 → 2。
- 多数据源、事务：1 的注册/默认组 → 2 的事务。
- 级联或代理：2 的事务 → 3。
- HTTP 或复制：1 的模块选择 → 4。
- 接口报文加密：1 的模块选择 → 6。
- 框架扩展：1 → 5。
- 自定义 SQL、统计报表：2，不把 QueryRequest、ModelGroupWrapper 换成其他 ORM 接口。
- SQLite/H2 选型或复现跑分：1 → 7。
- 查询缓存：2 → 8。

## 给 AI 使用

有仓库读取能力时提供 [llms.txt](../llms.txt)，只按任务加载专题。

只能上传一个附件时使用 [AI 接入指南](AI接入指南.md)：包含六个使用专题，不包含内部实现与历史跑分。扩展数据源或修改框架时再单独提供第五专题。

统一版本与准确包名在第一专题；每个示例区分完整类、方法体片段和业务占位，不假设全部可直接复制执行。SQL 与 HTTP 地址都需按业务替换。

## 文档维护

正文来源只有八个专题。修改 API、默认值或行为时更新对应专题及 AI 导出，不再维护旧目录的平行版本。文档导出清单位于 build-ai-docs.ps1；命令和验收范围见第五专题。

本轮于 2026-10-10 核对源码、lang 和缓存模块，已运行 SQLite/H2 业务口径 JMH、JDK 25 全模块测试编译、lang/缓存专项测试和 Schema 定向测试。第一专题的选型数据只适用于其中写明的环境和调用方式。

本目录保留的 admin.sql、code.sql、quartz.sql 是历史数据库脚本，不是文档或当前迁移方案，不自动执行，也不作为 AI 生成当前接口的依据。
