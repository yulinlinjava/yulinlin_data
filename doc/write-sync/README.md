## 建议顺序

- 大量写入：[批量与多连接](batch.md)；允许延后执行时看[写队列](queue.md)。
- 点击量、热度与统计明细：看 [EntityCounter](counter.md)，区分数字聚合与普通队列。
- 跨数据源：[增量同步](incremental.md) → [人工全量与续传](full.md)，先明确停写要求与一致性限制。
