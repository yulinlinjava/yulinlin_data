



# sql构造器

有4种类型，分别对应查询，插入，删除，更新



## 模型方式使用





### 注解说明

```
@JoinTable("sys_user")
标记表明


@JoinPrimary
是否为主键

@JoinField
标记是否位数据库列

@JoinWhere
标记查询条件，如果值存在，默认相等
```



### 定义数据模型类



```

@Data
@ApiModel("系统用户")
@JoinTable("sys_user")
public class SysUserEntity  {


        @NotEmpty(message = "必填")
        @ApiModelProperty("id")
        @JoinWhere
        @JoinField
        @JoinPrimary
        private String id;


        @NotEmpty(message = "必填")
        @ApiModelProperty("账号")
        @JoinWhere
        @JoinField
        private String username;

        @NotEmpty(message = "必填")
        @ApiModelProperty("昵称")
        @JoinWhere
        @JoinField
        private String nickname;


        @NotEmpty(message = "必填")
        @ApiModelProperty("邮箱")
        @JoinWhere
        @JoinField
        private String email;


        @NotEmpty(message = "必填")
        @ApiModelProperty("登录ip")
        @JoinWhere
        @JoinField
        private String loginIp;



        @NotEmpty(message = "必填")
        @ApiModelProperty("部门id")
        @JoinWhere
        @JoinField
        private String sysDeptId;


}

```

### 插入构造器

使用模型构造器解析对象，获得sql模型对象

```
    @Test
    public void insert(){


        //创建用户对象
        SysUserEntity e =  new SysUserEntity();
        e.setEmail("123@qq.com");
        e.setUsername("admin");
        e.setPassword("admin");

        //获得插入构造器
        ModelInsertWrapper wrappper =ModelInsertWrapper.newInstance(e);

        //查看sql
        String sql = wrappper
                //获取sql
                .getSql();

        //insert into  sys_user ( username , email , password , id )  values  ( #{0} , #{1} , #{2} , #{3} ) 
 
        //数据库执行
        //int total = wrappper.execute();


    }
```

### 删除构造器

接下来演示删除构造器

```
    @Test
    public void delete(){

        SysUserEntity e = new SysUserEntity();
        e.setId("1");
        //解析实体类 主键字段会作为删除条件，
        ModelDeleteWrapper wrapper =  ModelDeleteWrapper.newInstance(e);
        //查看sql
        String sql =  wrapper.getSql();
        //delete from  sys_user where id = #{0}
        //数据库执行
      	//int total =  wrapper.execute();

        //和上面等价，编程写法
         ModelDeleteWrapper.newInstance(SysUserEntity.class)
                //删除id = 1
                .eq("id",1)
                //获取sql
                .getSql();
     }
```



### 更新构造器

```
@Test

    SysUserEntity e = new SysUserEntity();

    e.setEmail("123@qq.com");
    e.setUsername("admin");

    //update  sys_user set username = #{0} , email = #{1} , password = #{2} where id = #		{3}
  

}
```
