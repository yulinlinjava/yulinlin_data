### 构造器

构造器有4种类型，分别对应增删改查4种，并且全部支持链式编程



#### 查询构造器



```
@Test
public void  select(){
    //new 一个查询构造器
    SelectWrapper wrapper =   new SelectWrapper();

    //设置表明
    wrapper.table("sys_user")
            //得到列对象
    .select()
            //添加返回列
    .column("username","username")
    .column("id","id")
    .column("phone_number","phoneNumber")
            //返回上一级
    .end()
            //得到条件对象
    .where()
            //查询条件时 id = 1
    .eq("id",1)

    ;

    //参数上下文
    SimpParams params =  new SimpParams();
    //构造一个mysql解析对象
    MysqlParseManager parse =    new MysqlParseManager();
    //解析构造器，获得sql语句
    String sql = parse.parse(wrapper,params);

    int a = 0;


}
```



解析出来的sql语句如下

```
select username as username , id as id , phone_number as phoneNumber from sys_user where id = #{0}
```

#### 条件构造器

在前面使用中，经常遇到where()方法，这个方法返回了一个StringConditionManager条件构造器

他的常用方法如下



通用条件方法

name 字段名 condition 条件枚举符号 value 值

```
condition(String name, ConditionEnum condition, Object value) 
```



ConditionEnum 枚举如下

```
/**
 * 运算符
 */
public enum ConditionEnum {
    

    // 等于
    eq("=","相等"),
    // 不等
    ne("!=","不等"),
    // 模糊
    like("like","模糊"),

    //右模糊
    likeRight("like","右模糊"),
    //多次模糊查询

    // 属于
    in("in","属于"),
    // 不属于

    // 大于等于
    ge(">=","大于等于"),
    // 大于
    gt(">","大于"),
    // 小于等于
    le("<=","小于等于"),
    // 小于
    lt("<","小于"),
    //范围
    between("between","范围"),
    isNull("is null","空"),
    ;

    private final String symbol;
    private final String name;


    ConditionEnum(String value, String name) {
        this.symbol = value;
        this.name = name;
    }



    public String getSymbol() {
        return this.symbol;
    }

    public String getLabel() {
        return this.name;
    }
    public String getValue() {
        return this.name();
    }
}
```



isNull(name)

查询字段值为null



谓词方法

下一个条件使用or链接，默认使用and

or()

下一个条件使用否定，默认不适用

not()

对前面的条件开括号

struct()

在回调函数内使用开括号

struct(ConditionFunction func) 



```
@Test
public void  where(){
    //new 一个查询构造器
    SelectWrapper wrapper =   new SelectWrapper();

    //设置表明
    wrapper.table("sys_user")
            //得到列对象
            .select()
            //添加返回列
            .column("username","username")
            .column("id","id")
            .column("phone_number","phoneNumber")
            //返回上一级
            .end()
            //得到条件对象
            .where()
            //查询条件时 id = 1
            .eq("id",1)
            //对前面条件开括号
            .struct()
            //开一个括号，然后在括号内添加新条件
            .struct(f -> {

                f.like("username","admin");
            })

    ;

    //参数上下文
    SimpParams params =  new SimpParams();
    //构造一个mysql解析对象
    MysqlParseManager parse =    new MysqlParseManager();
    //解析构造器，获得sql语句
    String sql = parse.parse(wrapper,params);

    int a = 0;
}
```



```
select username as username , id as id , phone_number as phoneNumber from sys_user where  ( id = #{0} )  and  ( username like #{1} ) 
```



#### 自定义表达式

func 字符串，args为参数列表

expression（String func,Object ... args）

例如，和eq("id",1) 等价

```
expression("id = ?",1)
```



注意的是，表达式过于灵活，可能不支持跨数据源，请慎用

#### 关键字替换



```
//参数上下文
SimpParams params =  new SimpParams();

params.putKeyAlias("nickname","nick_name");
//构造一个mysql解析对象
MysqlParseManager parse =    new MysqlParseManager();

String sql = parse.parse(wrapper,params);
```

可以看到，nickname 被替换nick_name
