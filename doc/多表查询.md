

### 定义模型类



```
@ApiModel("用户部门关联")
@Data
@JoinTable(left = "sys_user a",right = "sys_dept b",on = "a.sys_dept_id = b.id")
public class SysUserJoin {

    @ApiModelProperty("id")
    @JoinWhere
    @JoinField
    private String id;

    @ApiModelProperty("账号")
    @JoinWhere
    @JoinField
    private String username;

    @ApiModelProperty("部门名字")
    @JoinWhere
    @JoinField
    public String deptName;


}
```

如果有更多的表需要关联，使用@JoinTableList注解即可

如下所示：

```
@JoinTableList(value = {
        @JoinTable(left = "sys_user a",right = "sys_dept b",on = "a.sys_dept_id = b.id"),
        @JoinTable(right = "sys_dept b",on = "a.sys_dept_id = b.id")
})
```
