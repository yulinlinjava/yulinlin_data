



### 条件运算符

```
public enum ConditionEnum {
    

    // 等于
    eq("=","相等"),
    // 不等
    ne("!=","不等"),
    // 模糊
    like("like","模糊"),
    //not_like("not like","否定模糊"),
    // 左模糊
   // like_left("like","左模糊"),
    //右模糊
    like_right("like","右模糊"),
    //多次模糊查询

    // 属于
    in("in","属于"),
    // 不属于

    // 大于等于
    ge(">=","大于等于"),
    // 大于
    gt(">","大于"),
    // 小于等于
    le("<=","小于等于"),
    // 小于
    lt("<","小于"),
    //范围
    between("between","范围"),
    isNull("is null","空"),
    ;

    private final String symbol;
    private final String name;


    ConditionEnum(String value, String name) {
        this.symbol = value;
        this.name = name;
    }



    public String getSymbol() {
        return this.symbol;
    }

    public String getLabel() {
        return this.name;
    }
    public String getValue() {
        return this.name();
    }
}
```





除了插入，其他都有条件构造器

一般使用

```
//condition 是枚举对象
wrapper.condition(String name, ConditionEnum condition, Object value)
```

提供简写形式

wrapper.xx(字段名，值)，来设置条件



注意，这里的name，会被可以是字段名，也可以列明

当他是字段名时，他会会获得对应字段的列明，然后替换



### 字符串条件构造器

```
@Test
public void join2(){



    //模型解析
    ModelSelectWrapper<?> wrapper =   ModelSelectWrapper.newInstance(SysUserJoin.class);

    //设置条件
    wrapper.eq("id",1)
            .like("username","yy");



    //查看sql
    String sql =  wrapper.getSql();
    //select a.id as id , a.username as username , b.dept_name as deptName from  sys_user a left join sys_dept b on a.sys_dept_id = b.id left join sys_dept b on a.sys_dept_id = b.id 
    // where a.id = #{0} and a.username like #{1}
    
 
}
```



可以看到，where 哪里列明被改变了



### lambda条件构造器

条件构造器，支持lambda写法



```
@Test
public void lambda(){

    
    //模型解析
    ModelSelectWrapper<?> wrapper =   ModelSelectWrapper.newInstance(SysUserJoin.class);

    //设置条件,使用lambak方式
    wrapper.lambda()
            .eq(SysUserJoin::getId,"1")
            .like(SysUserJoin::getUsername,"yy");
    
    //查看sql
    String sql =  wrapper.getSql();
    //select a.id as id , a.username as username , b.dept_name as deptName from  sys_user a left join sys_dept b on a.sys_dept_id = b.id left join sys_dept b on a.sys_dept_id = b.id
    // where a.id = #{0} and a.username like #{1}


}
```
