### 模型构造器

为了简化sql拼写存在，分别有4个类型，和基础构造器一一对应



### 注解说明

```
@JoinTable("sys_user")
标记表明


@JoinPrimary
是否为主键

@JoinField
标记是否位数据库列

@JoinWhere
标记查询条件，如果值存在，默认相等
```



### 定义数据模型类



```

@Data
@ApiModel("系统用户")
@JoinTable("sys_user")
public class SysUserEntity  {


        @NotEmpty(message = "必填")
        @ApiModelProperty("id")
        @JoinWhere
        @JoinField
        @JoinPrimary
        private String id;


        @NotEmpty(message = "必填")
        @ApiModelProperty("账号")
        @JoinWhere
        @JoinField
        private String username;

        @NotEmpty(message = "必填")
        @ApiModelProperty("昵称")
        @JoinWhere
        @JoinField
        private String nickname;


        @NotEmpty(message = "必填")
        @ApiModelProperty("邮箱")
        @JoinWhere
        @JoinField
        private String email;


        @NotEmpty(message = "必填")
        @ApiModelProperty("登录ip")
        @JoinWhere
        @JoinField
        private String loginIp;



        @NotEmpty(message = "必填")
        @ApiModelProperty("部门id")
        @JoinWhere
        @JoinField
        private String sysDeptId;


}

```

### 多表查询

定义模型

```
@ApiModel("用户部门关联")
@Data
@JoinTable(left = "sys_user a",right = "sys_dept b",on = "a.sys_dept_id = b.id")
public class SysUserJoin {

    @ApiModelProperty("id")
    @JoinWhere
    @JoinField
    private String id;

    @ApiModelProperty("账号")
    @JoinWhere
    @JoinField
    private String username;

    @ApiModelProperty("部门名字")
    @JoinWhere
    @JoinField
    public String deptName;


}
```

如果有更多的表需要关联，使用@JoinTableList注解即可

如下所示：

```
@JoinTableList(value = {
        @JoinTable(left = "sys_user a",right = "sys_dept b",on = "a.sys_dept_id = b.id"),
        @JoinTable(right = "sys_dept b",on = "a.sys_dept_id = b.id")
})
```
