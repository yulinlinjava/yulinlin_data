### 模型之间数据联动

用户模型

```

@Data
@ApiModel("系统用户")
@JoinTable("sys_user")
public class SysUserEntity   {


        @NotEmpty(message = "必填")
        @ApiModelProperty("id")
        @JoinWhere
        @JoinField
        @JoinPrimary
        private String id;


        @NotEmpty(message = "必填")
        @ApiModelProperty("账号")
        @JoinWhere
        @JoinField
        private String username;

        @NotEmpty(message = "必填")
        @ApiModelProperty("昵称")
        @JoinWhere
        @JoinField
        private String nickname;


        @NotEmpty(message = "必填")
        @ApiModelProperty("邮箱")
        @JoinWhere
        @JoinField
        private String email;


        @NotEmpty(message = "必填")
        @ApiModelProperty("登录ip")
        @JoinWhere
        @JoinField
        private String loginIp;



        @NotEmpty(message = "必填")
        @ApiModelProperty("部门id")
        @JoinWhere
        @JoinField
        private String sysDeptId;
        
        //查询用户部门
        public SysDeptEntity findSysDept(){
              return   ModelSelectWrapper.newInstance(SysDeptEntity.class)
                      //主键查询简写，等价 
                      // eq("id",sysDeptId)
                        .eq(sysDeptId)
                        .selectOne();
        }

}

```



部门模型

```
@Data
@ApiModel("系统部门")
@JoinTable("sys_dept")
public class SysDeptEntity  {

        @NotEmpty(message = "必填")
        @ApiModelProperty("id")
        @JoinWhere
        @JoinField
        @JoinPrimary
        private String id;


        @NotEmpty(message = "必填")
        @ApiModelProperty("部门名称")
        @JoinWhere
        @JoinField
        private String deptName;
        
        //查询部门下面所有用户
        public List<SysUserEntity> findSysUserList(){
               return ModelSelectWrapper.newInstance(SysUserEntity.class)
                        .eq("sysDeptId",getId())
                        .selectList();
        }



}
```



上面这种通过自定义查询方法实现，推荐这种写法



### 级联查询注解



```
@JoinQuery(primary = "id",value = "sysDeptId")
primary 模型类主键字段名，默认id
value 从当前模型取值字段
```



value 取值字段，多级使用.分割



但也有另外一种写法，使用注解实现，在部门模型哪里，加上该注解即可

```
//查询
@JoinQuery(primary = "sysDeptId",value = "id")
private List<SysUserEntity>  sysUserEntities;
```



他会在数据查询出来后，再去加载数据



同样，用户哪里也可以使用这个注解

```
//查询用户部门
@JoinQuery(primary = "id",value = "sysDeptId")
private SysDeptEntity sysDeptEntity;
```



这样会导致循环依赖问题，这个是因为加载数据期间，互相初始化导致的



### 懒加载，事务必须开启

使用懒加载注解解决互相引用问题

```
@JoinLazy
```

级联查询加了注解后，当该字段被get时，会触发数据加载



### 懒同步，事务必须开启

以前同步数据，你得靠new 一个对象，然后set值，再设置条件更新

```
@JoinSync
```

标记了这个注解的字段，当对象被set后，在事务提交前

会同步到数据库去

如果对象没有发生修改操作，不会同步
