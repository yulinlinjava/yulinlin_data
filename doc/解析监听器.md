## 数据权限

在某些xx管理系统开发中，经常遇到这么一个问题，为某些操作，动态插入赋予查询条件。



例如：

总经理可以查看全部用户

部门经理可以查看本部门内的用户

组长可以查看本组内的用户



又或者是，

总经理可以查看所有连锁店铺的员工信息

区域负责人可以查看负责区域店铺员工信息

店长可以查看本店员工信息



等等诸如此类的，这种业务特点是，限制某某人可以查看那些数据



这里采用sql监听器，完成这种动态条件植入



注册一个解析监听器

```
@Component
public class SysUserListener implements INodeListener<SelectWrapper> {

    //返回可以查看的部门集合
    private List<String> sysDeptId(){
        return Arrays.asList("1","2");
    }

    @Override
    public void listener(SelectWrapper node, IParams params) {
        //是否单表
        if(node.getFrom() instanceof Store){
            Store store =(Store) node.getFrom();
            //判断是否sys_user 表
            if(store.getName().equals("sys_user")){
                //动态添加条件
                node.where()
                        .struct()// 对已有条件开括号
                        //限制当前查询只能查看指定部门数据
                        .in("sys_dept_id",sysDeptId());
            }
        }

    }
}
```





编写单元测试，查看效果

```
    @Test
    public void test()throws Exception{
        ModelSelectWrapper.newWrapper(SysUserEntity.class)
                .like("nickname","admin")
                .selectList();
    }

```



可以看到，控制台打印如下sql语句，动态添加条件成功了

```
[%admin%, 1, 2]
```



## 字段权限



在某些系统中，会有一些敏感字段的问题。



他的业务要求时，具备这个字段权限的人，就可以查看这个字段值，否则就不行



这个问题，同样可以用监听器来动态处理



```
@Component
public class SysUserListener implements INodeListener<SelectWrapper> {

 

    @Override
    public void listener(SelectWrapper node, IParams params) {
        //是否单表
        if(node.getFrom() instanceof Store){
            Store store =(Store) node.getFrom();
            //判断是否sys_user 表
            if(store.getName().equals("sys_user")){

                //对返回列删除
                node.select().removeIf(item -> {
                    //允许返回账号
                    if(item.getAlias().equals("username")){
                        return false;
                    }else if(item.getAlias().equals("nickname")){
                        //允许返回昵称
                        return false;
                    }
                    //其他删除
                    return  true;
                });
            }
        }

    }
}
```
